# Ethical Editorial Gate

## Overview

This umbrella skill combines three high-frequency safeguards:

1. **`veil-of-ignorance`** — enumerate stakeholders and hidden distributional harm.
2. **`anti-racist-review`** — check standing, framing, and identity-power distortions.
3. **`buzz-saw-editor`** — compress and stress-test argument logic.

Use this sequence before publishing decisions, memos, exclusion rationales, and externally-facing claims.

## When to Use

- Exclusion policy rationale or changes
- Research conclusions with social or distributional impact
- Client-facing or public-facing argument-heavy writing
- Any draft where “this sounds right” is doing more work than evidence

## Workflow

### Pass 1 — Stakeholder justice lens
Run `veil-of-ignorance`.
Output: explicit list of affected stakeholders, burdens, and open unknowns.

### Pass 2 — Standing and bias lens
Run `anti-racist-review`.
Output: standing gaps, framing risks, and corrections needed before release.

### Pass 3 — Argument integrity lens
Run `buzz-saw-editor`.
Output: logical chain, flagged weak claims, and tightened final argument.

### Pass 4 — Domain finalization
If the artifact is exclusion-policy content, run `writing-exclusions` for domain tone/structure.

## Common Pitfalls

1. Treating one pass as sufficient when all three lenses are needed.
2. Using ethical framing language without standing-backed evidence.
3. Editing for style before proving argument structure.

## Verification Checklist

- [ ] Veil-of-ignorance stakeholder pass completed
- [ ] Anti-racist standing/framing pass completed
- [ ] Buzz-saw logical audit completed
- [ ] Final artifact reflects corrections from all passes
